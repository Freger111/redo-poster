# РЕДО — автопостер NFT-канала

Бот собирает обложки в фирменном стиле, публикует посты по расписанию
и делает дайджест новостей из RSS. Работает на чистом Python: Pillow для
графики, остальное — стандартная библиотека.

## Возможности

- 🖼 **Обложки 1080×1080** — чёрный фон, лаймовый акцент, автоматическая вёрстка заголовка
- 🕙 **Расписание** — несколько слотов в день (`POST_TIMES`)
- 📚 **Очередь постов** — `data/queue.json`, посты публикуются по одному
- 📰 **Дайджест** — 5 свежих новостей из RSS со ссылками на источники
- 🧪 **Самопроверка** — `--selftest` работает без токена и сети

## Быстрый старт

```bash
pip install -r requirements.txt

# 1. Создайте .env (пример — .env.example)
cp .env.example .env

# 2. Проверьте без публикации
python main.py --preview
python main.py --selftest

# 3. Запустите
python main.py --loop
```

Бот должен быть **администратором канала** с правом «Публикация сообщений».

## Команды

| Команда | Что делает |
|---|---|
| `--preview` | рисует обложку следующего поста в `data/out/` |
| `--post-now` | публикует следующий пост сразу |
| `--digest` | собирает дайджест из RSS и публикует |
| `--add "ТЕГ\|Заголовок\|Текст"` | добавляет пост в очередь |
| `--loop` | работает по расписанию |
| `--selftest` | проверяет логику без токена и сети |

## Деплой на хостинг

Docker собирается из `Dockerfile`: ставит Pillow и шрифты DejaVu, запускает
`main.py --loop`.

Переменные окружения в панели хостинга:

```
BOT_TOKEN=токен_бота
CHANNEL=@RedoNFT0
CHANNEL_LINK=t.me/RedoNFT0
POST_TIMES=10:00,18:00
TZ_OFFSET=3
```

**Важно:** смонтируйте том на `/app/data` — там очередь постов и состояние
публикаций. Без тома всё обнулится при пересборке.

## Структура

```
redo-poster/
├─ main.py      команды и цикл расписания
├─ render.py    обложки 1080×1080
├─ content.py   очередь и состояние
├─ poster.py    отправка в Telegram
├─ digest.py    RSS → дайджест
├─ config.py    токен, канал, шрифты, бренд
└─ data/        queue.json, state.json, out/
```

## Безопасность

- `.env` с токеном в репозиторий не попадает (`.gitignore`).
- Токен бота даёт право писать в канал — не публикуйте его.
- Если токен засветился — перевыпустите в [@BotFather](https://t.me/BotFather).
